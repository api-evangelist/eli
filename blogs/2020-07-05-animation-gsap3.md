เมื่อเพื่อนๆอ่านบทความนี้จบ จะพบว่า การทำ Animation บนเว็บไซต์นั้นจะไม่ใช่เรื่องยากอีกต่อไป!! ทำไมหน่ะหรอ… ก็วันนี้เราจะพาทุกคนไปรู้จักกับ Javascript Animation Platform ที่จะช่วยเปลี่ยนหน้าเว็บอันสุดแสนจะธรรมดาของเรา ให้กลายเป็นเว็บไซต์ที่มีลูกเล่นเจ๋งๆ ยังไงล่ะ~ นักพัฒนาเว็บไซต์หลายๆ คนอาจจะรู้จักผ่านตา หรือเคยใช้เจ้าสิ่งที่เรียกว่า GSAP กันมาบ้างแล้ว แต่สำหรับคนที่ยังไม่รู้จักนั้น เจ้า GSAP หรืออีกชื่อหนึ่งก็คือ Green Sock Animation Platform เป็น Javascript Library ยอดนิยมสำหรับทำ Animation...
