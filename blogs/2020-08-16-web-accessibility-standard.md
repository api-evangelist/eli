Web Accessibility Standard : ความสามารถและการเข้าถึงเว็บไซต์โดยไม่มีข้อจำกัด หากพูดถึง Accessible design คนส่วนใหญ่จะนึกถึงกระบวนการออกแบบที่เป็นการแก้ปัญหาสำหรับคนที่มีข้อจำกัดทางด้านร่างกาย ไม่ว่าจะเป็นการมองเห็นหรือการได้ยินเท่านั้น แต่วันนี้เราอยากจะมาพูด Accessible design ในส่วนที่เป็นมาตรฐาน ประสบการณ์การใช้งานและแนวทางที่ดี โดยมีเป้าหมายหลักคือ การทำเว็บไซต์ที่ใช้งานได้สำหรับทุกคน ไม่ว่าจะมีหรือไม่มีข้อจำกัดทางด้านร่างกาย อารมณ์ และจิตใจก็ตาม Web accessibility Standard...
